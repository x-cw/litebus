1. Overview

1.1 Purpose

本文档主要供 DE 与 DV 工程师使用。描述 LiteBus BASIC-CORE 的内部协议、接口打包、约束与 RTL 实现，对应冻结目录 litebus_rtl/。

  1. 第 2 章描述外部 Valid-Ready 接口与内部 Credit 接口。
  2. 第 3 章描述 Flit 描述符、opcode / resp 编码、三种 ID 变迁。
  3. 第 5 章给出 BASIC-CORE 原则与 feature。
  4. 第 7 章按模块给出 I/O、功能与硬件实现。

LiteBus 的研发动机来自 GP3A FlexNoC 落地痛点：BIF→AXI 协议税、强制同 ID 保序 CAM、两通道读写竞争、Valid-Ready 双向时序与布线拥堵、商业 IP 黑盒。LiteBus 的对策是：BIF 友好的自定义接口、同 ID 从 BASIC 剥离、四通道分离、Credit 流控、白盒可扩展。

BASIC-CORE

  • INIU / TNIU / Switch / Link
  • 四通道、Credit、事务级仲裁
  • 相位对齐位宽转换
  • 读交织 fragment（TNIU 适配）
  • 可选 RR-QoS、Atomic

EXTENDED-CORE（规划，不在本 RTL）

  • AXI/APB ↔ LiteBus Adaptor
  • Narrow burst merge
  • Burst split / Simple split
  • One_trans_fly / ROB
litebus_rtl 中 INIU/TNIU adaptor 的 EXT_PROTOCOL=AXI/APB 仅为 TODO 占位；真正的 AMBA 桥在仓库 rtl/adapter_*.v，不属于 BASIC-CORE，本文不展开 adapter。

1.2 Top Diagram

BASIC-CORE 由 Initiator NIU、Fabric（Switch + Link）、Target NIU 组成。Master / Slave 侧为 Valid-Ready；NIU 内部与 Fabric 之间为 Credit。四条物理通道全程分离：REQ_R、REQ_W、RSP_RD、RSP_WR。

模块职责

  • INIU：外部 CMD 译码为网络 CMD flit（DestID、SrcID、addr_local、total_bytes、IntID）；REQ_R / REQ_W 两条完全并行链，互不仲裁。
  • Switch：按 DestID（请求）或 SrcID（响应）查路由表；事务级仲裁；可选 XBAR FIFO 缓解 HOL；HAS_LAST 通道做 burst-lock。
  • Link：PIPE（信用打拍）、NODE（信用分段）、BCA（跨时钟）、Unify（位宽转换）。Switch 本身等宽，转换全部下放到 Unify-LINK。
  • TNIU：共享 CMD TABLE 分配 LID；cmd_conv 重建 Slave len；lane_pack 生成范围 STRB；读交织时 rsp_rd_frag 把 beat 切成独立 fragment。

1.3 Workflow

写事务

Master REQ_W→ ext_pipe→ id_decode→ credit_egress→ int_pipe→ Switch / Link→ TNIU ingress→ cmd_table→ cmd_conv + lane_pack→ Slave
Slave RSP_WR→ 查表释放 LID→ credit_egress→ Switch 按 SrcID→ INIU ingress→ Master

写请求每拍一张 REQ_W flit（CMD 在突发内重复，WD 逐拍变化）。TNIU 仅在首拍分配 CMD 槽，后续拍复用 burst_lid，并用 wd_beat_idx 驱动 lane_pack。

读事务

Master REQ_R→ id_decode→ Fabric CMD-only→ cmd_table + cmd_conv→ Slave
Slave RSP_RD 可交织→ rsp_rd_frag→ Switch burst-lock on last→ INIU 截 IntID→ Master 见 trans_last

为何 fragment 能与事务级 Switch 共存

Switch 不感知“母事务”，只认 HAS_LAST 通道上的 last。TNIU 把 Slave 交织返回的每一拍（或拼好的 FB 块）变成带独立 Lane / Total_bytes / last 的 fragment。对 Switch 而言每个 fragment 仍是不可打断的完整“事务”。INIU 用 trans_last 还原 Master 语义上的 burst 结束。

2. Interfaces

复位约定：rst_n 异步置位、同步释放，由顶层 CRM 做同步释放。时钟在 NIU 两侧可不同（BCA 形态）；同域形态无 BCA。

2.1 Clock / Reset

信号位宽方向描述
clk / clk_m / clk_s1input网络域 / Master 域 / Slave 域时钟。
rst_n / mrst_n / srst_n1input对应域低有效复位。
clk_w / wrst_n1inputLink / BCA 写侧（上游）时钟复位。
clk_r / rrst_n1inputLink / BCA 读侧（下游）时钟复位。同域时与 clk_w 绑在一起。

2.2 External IP（Valid-Ready）

Master↔INIU 与 TNIU↔Slave 使用同一套 LiteBus 外部语义。通道独立握手。参数范围见第 5.2 节。

REQ_W

信号位宽方向描述
req_w_valid / req_w_ready1双向握手Valid-Ready。Master→INIU 或 TNIU→Slave。
req_w_opcode4请求方向4'h8 普通写；4'hC/D/E/F 原子。bit3 必须为 1，否则全网当读处理。
req_w_addr8–64请求方向Master 侧全局地址；Slave 侧 local 地址。
req_w_len1–12请求方向拍数 − 1。len=0 表示 1 拍。
req_w_txnid1–16请求方向Master 侧 ExtID。TNIU 侧为 LID，Slave 必须原样回传。
req_w_user0–64请求方向CMD 边带。宽度 0 时顶层省略引脚。
req_w_wdata / req_w_wstrb8–1024 / DW/8请求方向写数据与字节使能。数据位宽 2^n。
req_w_wlast1请求方向写突发末拍。Switch REQ_W 的 burst-lock 锁此位（内部 WD.last）。
req_w_modifier0–7请求方向原子修饰符。INT_MOD_W=0 时整段消失。
req_w_qos0–4请求方向数值越大优先级越高。只存在于请求；响应由 TNIU 查表带回。

REQ_R

信号位宽方向描述
req_r_valid / req_r_ready1双向握手独立于 REQ_W，读请求不会排在写数据后面。
req_r_opcode4请求方向bit3=0 为读。RTL 默认 4'h1。
req_r_addr / len / txnid / user / qos同 CMD请求方向无 WD。网络内 REQ_R flit 宽度等于 CMD flit，不做数据位宽转换。

RSP_RD

信号位宽方向描述
rd_valid / rd_ready1双向握手Slave→TNIU 或 INIU→Master。
rd_last1响应方向到达 Master 的是 trans_last（事务级）。内部 fragment 级 last 不得出网。
rd_resp2响应方向见 3.2。总线透传，自身不生成。
rd_txnid / rd_user / rd_data参数化响应方向无 byte_valid 引脚：接收端用 (addr_lane, total_bytes, beat) 重建有效字节。

RSP_WR

信号位宽方向描述
wr_valid / wr_ready1双向握手单拍写响应。
wr_resp / wr_txnid / wr_user2 / 1–16 / 0–64响应方向无 last、无 data。HAS_LAST=0，Switch 不 burst-lock。
外部打包（INIU 参数，MSB→LSB）： EXT_CMD = {qos, opcode, addr, len, txnid, user}； EXT_WD = {data, strb, last, txnid}； EXT_REQ_W = {CMD, mod, WD}； EXT_RSP_RD = {txnid, resp, user, last, data}； EXT_RSP_WR = {txnid, resp, user}。

2.3 Internal Fabric（Credit）

内部接口无 ready。发送端 out_valid 仅在仍有 credit 时拉高；对端 pop 时脉冲 credit_return。Credit 初值必须等于对端 ingress FIFO 深度，由拓扑生成器配对。

信号方向描述
*_flit / *_valid下游前向 flit。无 ready。
*_credit_ret上游每 pop 一拍脉冲。可与发送同拍（零延迟 return）。

四通道各有独立 credit 环，互不借用。PIPE 形态不消耗/产生 credit，只对 payload+valid 与 credit_return 对称打拍，端到端仍是一条 credit 环，初值需覆盖往返寄存器数。

3. Descriptors

3.1 Flit Packing

打包顺序 MSB→LSB。字段宽度全部来自模块参数；lb_defines.vh 只固定常量与字段次序。Pipe / credit / bca 把 flit 当不透明向量搬运，只有 id_decode 与 NIU adaptor 解码字段。

CMD flit（即 REQ_R 整包）

qos opcode addr_local total_bytes user int_id dest_id src_id 
INT_CMD_FLIT_W = INT_QOS_W + 4 + INT_ADDR_LOCAL_WIDTH + INT_TOTBYTES_W
                 + INT_USER_WIDTH_CMD + INT_ID_WIDTH + INT_DEST_ID_WIDTH + INT_SRC_ID_WIDTH
qos / user 宽度为 0 时该字段从 flit 中消失，而不是塞 0 占位（与“本 Master 无引脚、总线仍有该字段”不同：后者零填充）。

WD flit（REQ_W 低半部）

last strb data dest_id=0 src_id=0

WD 半包的 dest/src 恒 0：REQ_W 由 CMD 半包的 dest_id 路由。

REQ_W flit

CMD mod WD

一拍同时携带命令与写数据。写突发期间 CMD 重复。INT_MOD_W=0 时无 mod 段。

RSP_RD flit（低→高列出，src_id 在 MSB，供回程 Switch 与前向 dest_id 同位）

src_id qos addr_lane total_bytes int_id resp user trans_last last data
位语义消费者
lastFragment 级末拍。Switch burst-lock 锁这一位。仅 Fabric 内部，不得出 IP。
trans_last母事务末拍。INIU 将其接到 Master 的 rsp_rd_last。Master IP。
不变量：trans_last ⇒ last。由 lb_tniu_rsp_rd_frag 建立（o_trans_last = o_last && s_tl）；Unify DOWN 会暂时打破（trans_last 骑在 sb[0]，每个子拍都会出现）；lb_rsp_rd_unify_adapt 用 o_tl = o_sb[0] && o_last 恢复。INIU 若看到 trans_last 而 last=0 会仿真报错。

RSP_RD 不携带 byte_valid：512-bit 可省 47 bit/拍。接收端按 R4 重建 mask。

RSP_WR flit

src_id qos int_id resp user

宏值通道说明
LB_OP_RD4'h1REQ_Rbit3=0。
LB_OP_WR4'h8REQ_Wbit3=1。仅 B 响应。
LB_OP_ATOMIC_STORE4'hCREQ_W仅 B。释放时机与普通写相同。
LB_OP_ATOMIC_LOAD4'hDREQ_WB + R。CMD TABLE 收齐两者才释放。
LB_OP_ATOMIC_SWAP4'hEREQ_WB + R。

RTL 只解码 opcode[3] 判断读写族。写 opcode 若 bit3 清零，会在错误通道上被当成读，静默错误。TNIU 对 REQ_W 另有写 opcode 断言。

宏值说明

LB_RESP_FAIL2'b01失败（RTL）。
LB_RESP_ATOMIC_FAIL2'b10ATOMIC_COMPARE 失败，仅透传。
principle / motivation 文档写 rd_resp：2'b00 OK、2'b10 FAIL。RTL lb_defines.vh 将 FAIL 定为 2'b01，并把 2'b10 留给原子比较失败。以实现为准。Adapter 与 DV 不得混用两套编码。

3.3 ID Model

三种身份

  • ExtID（Master）：原生 txnid。BASIC 不允许网络中同时存在同 ID（含 RR / WW / 普通与原子）。INIU 不查重、不反压 outstanding，闸门在 Master / EXTENDED。
  • IntID：零扩展到网络最大 ID 位宽。
  • SrcID / DestID：INIU 注入 SrcID=NIU_ID；id_decode 用 (addr & MASK)==BASE 并行命中区域得到 DestID，addr_local = addr & ~MASK。
  • LID：只存在于 TNIU↔Slave。Fabric 用 {src_id, dest_id, int_id}。LID 是表项下标，零扩展到 Slave txnid 位宽；回程截断后查表。dest_id 不入库（本 TNIU 即目的地）。

回程：Slave 回传 LID → 查表还原 src_id / int_id / qos /（读）addr_lane+total_bytes → Switch 按 SrcID 路由 → INIU 截 IntID 为 Master ExtID。

CMD TABLE 不记录同一 {SrcID, IntID} 的到达顺序，因此 不支持同 ID。仿真对同 (int_id, src_id) 双活条目报警。

4. Design Constraints

  • BASIC-CORE 不允许同 ID。CMD TABLE 满则 TNIU 反压。INIU 无 pending 闸门。
  • MASTER 的 (len+1)×wdata 不得超过 SLAVE 的 MAX Burst Size；超限必须在 EXTENDED 或 Master IP 侧拆包。BASIC 不做自主拆包。
  • 有读交织的 PAIR：Master 位宽最好 ≤ Slave，否则 TNIU 必须部署 Assembly Buffer（深度 = Pendingtrans，宽度 = W_frag）。Slave Pendingtrans 宜小。
  • 有 Atomic 且 Master 位宽 > Slave 时，对齐 single 原子在 Slave 会变成 burst 原子。当前 L2 不支持 Burst Atomic，故有 Atomic 需求的 Master 位宽必须 ≤ Slave。
  • 末拍对齐到 Initiator 位宽。Slave 可能看到比 Master 感兴趣范围更大的地址窗。普通读多读无副作用（无 Read-Clear）；普通写靠 STRB 屏蔽；Unify 小转大会把扩展 STRB 清零。
  • Addition（收紧有效区间）暂不实施，由 Master IP 适配。
  • QoS 仅 Switch 消费。响应通道无 QoS 引脚，必须在 TNIU 锁存并带回。不建议把大部分事务打满高优先级；同优先级退化为 RR，全 0 与全 15 无带宽差。
  • Credit 配对：egress CREDIT_INIT 必须等于下游 ingress DEPTH。错配会静默丢拍。PIPE 形态初值需覆盖往返打拍数。
  • 内存映射区域必须互不重叠。重叠时 AND-OR 会把 Dest 常量按位或在一起，而非 last-match-wins。
  • 数据位宽必须 2^n。lane_pack / gearbox 用移位代替乘除；非 2^n 会算错 STRB 或推断除法器。
  • BCA 深度必须 2^n。RdPtr/Data 是同周期组合路径，延迟必须 < 1 个 clk_r，禁止在该路径插同步器。
  • 同域 TNIU 必须打开 EXT_PIPE_RSP_*，否则 Slave 的 rsp valid 会组合穿过查表、fragment、credit_egress。
  • 写突发中途不得把 alloc_w_ready 再挡后续 WD 拍（TNIU 用 is_first_beat 保护），否则最后一条表项会卡死突发。
  • Slave 必须原样回传 LID。错误回传会还原错误 SrcID，打断回程路由或 burst-lock。

5. Requirements / Feature Description

5.1 Feature List

  • 自定义 LiteBus 接口；Valid-Ready 端侧；内部 Credit。
  • 读/写 INCR burst；Atomic Store / Load / Swap / Compare（EXT_ATOMIC_EN）。
  • 非对齐起始；无 AXI size 字段。窄带由 EXTENDED 在进网前处理。
  • 读响应交织（TNIU fragment + 可选 assembly）。
  • 四通道分离：RR / WW 保序；RW / WR 不保序（Master 做 address overlap 检查）。
  • Switch：FIX / RR / RR-QoS；XBAR FIFO 缓解 HOL；事务级仲裁 + last burst-lock。
  • Link：PIPE、NODE、BCA、Unify。
  • 不同 Master/Slave 位宽经 Unify 统一；CMD / user / qos 按通道独立取网络最大值并零扩展。
  • 不支持：同 ID、BASIC 内拆包、广/组播、Addition、NIU 内 AMBA 转换（占位）。

5.3 Principles（与 RTL 对应）

5.3.1 相位型事务定位标

互联本质是“访问一段连续字节区间”。外部保留 Address + Len（无 Size）；入网后变为 Lane + Total_bytes，使任意次位宽转换仍不丢范围。

Lane        = Slice(Address)          // 即 addr 在当前 W 下的字节相位
Total_bytes = (Len+1) × Wdata_mst/8 − (Address mod Wdata_mst/8)
有效区间    = [Lane, Lane + Total_bytes − 1]

INIU 实现（避免全宽减法）：
  beats     = len + 1
  off       = addr[log2(bytes_per_beat)-1:0]
  beats_adj = beats - (off != 0)
  low       = -off          // 即 2^B − offset
  total     = {beats_adj, low_bytes}     // 低 B 位不向高位借位以外的 ripple

Unify 四级规则（lb_unify_gearbox）：

规则定义含义
R1 落位字节 A 恒在 beat[A/W] 的 lane A mod W与转换历史、事务起点无关。
R2 拍集合k ∈ [⌊addr/W⌋, ⌊(addr+tb−1)/W⌋]与 [addr, addr+tb) 不相交的拍就地剔除。
R3 拍数N(W) = 上式差 + 1该位宽下理论最少拍。
R4 有效性lane j 有效 ⇔ addr ≤ k·W+j < addr+tb接收端只凭 (addr, tb, k) 重建 mask。

示例：外部 Address=0x17、Len=1、4B 数据 → Lane=7、Total_bytes=5。4B→2B 剔除空拍；2B→8B 引入冗余窗，写 STRB 为 0。

5.3.2 事务级 Switch 仲裁

事务级（采用）Flit 级（不采用）
规则出口授权后直到 last 才释放每拍可换事务，出口交织
重排端侧无需 ROB端侧常需 ROB
翻转头拍仲裁、末拍释放每拍仲裁
HOL较重，用 XBAR FIFO 换较轻

实验：16×16 两级 XBAR、FIFO 深度 8，出口空转可压到约 10%。RTL 把路由译码移到 ingress FIFO 写侧，与仲裁/mux 错开同一拍关键路径。

5.3.3 读交织 Fragment

Slave（如 DDRC）可在同 ID 保序前提下穿插多笔读数据。TNIU 将每拍变为独立 fragment。若 Slave 位宽 < Master，不足一拍的 small fragment 不能直接回 Master，必须在 Assembly Buffer 拼成 FB 后再发。缓冲规格：每 LID 一项、一项只持有一个 FB 而非整笔事务。

5.3.4 QoS

局部 QoS，唯一消费者是 Switch。RR-QoS（ARB_SCHEME=2）在仲裁器前做支配滤波：只有当前最高 pending QoS 的请求者进入 RR。比较值在无 XBAR FIFO 时是头拍 qos；有 FIFO 时是队列内最大值（lb_sw_qos_track 温度计计数）。Burst-lock 优先于 QoS：锁定突发必须发完。

网络侧（lb_iniu_int_core）关键端口：

IP 侧（lb_iniu_ext_core）在 EXT_PROTOCOL=0 时为打包/解包直通。RSP_RD 解包字段：data、last、resp、ext_txnid、user。

7.1.2 Function

  1. REQ_R 与 REQ_W 两条完全并行链：各自 ext_pipe、id_decode、credit_egress、int_pipe。代价是内存映射比较器翻倍；共享译码再仲裁会把两通道重新绑到同一资源。
  2. id_decode：并行区域命中 + 一热 AND-OR（深度 log2(NUM_REGION)），避免线性优先级链。DestID 与 addr_local 同期组合完成，握手直通，无内部缓冲。
  3. total_bytes 用“低位取补 + 高位条件减 1”代替全宽减法，缩短 INIU 前向关键路径。
  4. INT_* 为网络全局最大宽度；窄 Master 零扩展。INIU 回程不读 src_id/qos，用从 LSB 锚定的偏移切片，字段增宽不破坏解包。
  5. 无 CMD TABLE、无 outstanding 反压。

7.1.3 Hardware

IP VR→ ext_core unpack/pack→ [optional BCA]→ ext_pipe skid→ id_decode ×2→ credit_egress→ int_pipe→ Fabric

回程相反：int_pipe → credit_ingress → ext_pipe → 截 IntID → Master。八个 PIPE 使能位独立（四通道 × EXT/INT）。

WD 组装：{w_last, w_strb, w_data, dest=0, src=0}。REQ_W = {dec_cmd_flit, [mod], wd_flit}。写突发每拍一张 flit。

内存映射注入方式 A：生成器把 REGION_BASE / MASK / DEST 打成 flattened 参数。命中条件 (addr & MASK)==BASE。

7.2 TNIU

7.2.1 I/O

信号 / 参数描述
i_req_r_flit / i_req_w_flit网络入。对应 credit_ret 回给上游。
o_rsp_rd_flit / o_rsp_wr_flit网络出。
EXT_PENDING_TRANSCMD TABLE 深度。LID 宽度由它派生，禁止外部覆盖。
EXT_RSP_RD_INTERLEAVE1 插入 lb_tniu_rsp_rd_frag。
EXT_ATOMIC_EN1 启用双响应原子槽。
WFRAG_DW该 Slave 上 Master 最大数据位宽。

7.2.2 Function

  1. CMD TABLE 单池：读口取最低空闲（lsb_onehot），写口取最高空闲（msb_onehot）。≥2 空闲时可同拍双分配；只剩 1 个时寄存器 RR 决定归属。ready 只是 cnt_free 与 rr_ptr 的函数，两通道无组合耦合。容量共享：一方打满表会拉低另一方 ready。
  2. alloc_*_req 必须已折入下游 ready，避免占着最后一项却发不出去。
  3. 写通道仅首拍分配；ci_req_w_r = (is_first_beat ? alloc_w_ready : 1) && ep_ready。
  4. cmd_conv：len = ceil((addr_lo + total_bytes)/SLV_B) − 1，恒等变形为 floor((x−1)/B)，一次加法加移位。total_bytes=0 时 len=0。
  5. lane_pack：数据已相位对齐，不再桶形移位。STRB = 范围掩码 AND 上游 strb。范围比较拆成拍级一次比较 + 每 lane 温度计。
  6. rsp_rd_frag：beat → fragment。SLV≥W_frag 时每拍即一 fragment，无需 SRAM 式拼拍；SLV<W_frag 时收集 RSPAN 拍。每 LID 一项缓冲。s1 寄存器把查表与区间算术拆拍，曾是 2.5 GHz 关键锥。
  7. 原子 LOAD/SWAP/COMPARE：opcode bit[3:2]=11 且低两位非 00。STORE（4'hC）只收 B。B 与 R 可同拍到达，释放仲裁保证只释放一次。
  8. QoS 在分配时写入 qos_mem，响应查表插入 RSP flit 顶部，供回程 Switch 仲裁。

7.2.3 Hardware

查表端口为何也要拆开

RSP_RD（多拍）与 RSP_WR（单拍）可能同拍返回。若共用一个 lookup + free 选择器，写响应会抢读响应的 LID，造成突发中途 SrcID 改变，打断回程路由与 burst-lock。故 rsp_rd_lid / rsp_wr_lid 与 free strobe 成对独立。非原子条目同拍不得指向同一项（断言）；原子条目是唯一合法同项双响应。

lb_tniu_ext_core 即使 PROTOCOL=0 也不是纯连线：它把 REQ_W 拆成 cmd/wd 进 adaptor，再在 Slave 口拼回。写检测不再看 opcode——REQ_W 天生是写。

LID 深度不必 2^n。超出 EXT_PENDING_TRANS 的编码是空洞，响应路径用显式范围门（PEND_POW2 / g_rng_chk）。

rsp_rd_frag 要点

  • FB = max(SLV_bytes, W_frag/8)；RSPAN = FB / SLV_bytes。
  • 完成队列深度 = Pendingtrans；指针按 2^QW 自然回绕，存储上取整到 QSLOTS，避免非 2^n 深度下 LID 错配（曾在 depth=64 时拍数对、62 个 LID 错）。
  • 同一 LID 在 fragment 未出队时不能再收拍（fdone）。吞吐靠多 LID 轮转，单 LID 受“一项缓冲直到 fragment last 送出”限制。
  • 无 ROB：假设 Master 接受带 ID 的交织读返回。

7.3 Switch

7.3.1 I/O

模块 lb_sw_route：每通道一个实例（REQ_R / REQ_W / RSP_RD / RSP_WR），端口等宽。Verilog-2001 用 flattened 1-D bus。

参数含义
ROUTE_TABLEflat [NUM_DEST×OW]，DestID → 出口下标。
CONNECTIVITY_MASK[i×NUM_OUT+o]=1 表示存在物理连接。
DEST_LSB路由字段在 flit 中的位置。请求用 dest_id，响应用 src_id（放在 flit 顶端对齐）。
HAS_LAST / LAST_POSWD / RSP_RD 为 1；CMD / RSP_WR 为 0。
ARB_SCHEME0 FIX，1 RR，2 RR-QoS。
CREDIT_DEPTH_VEC / OUT_DEPTH_VEC / EGRESS_CREDIT_VEC每端口独立深度，避免短链路为长链路买单。
XBAR_FIFO_DEPTH每 crosspoint FIFO。0=旁路（组合）。合法 0 或 2–64 任意整数。

7.3.2 Function

每输入：credit_ingress →（写侧路由译码）→ crossbar → out_fifo → credit_egress。

无 XBAR FIFO 时，输入 ready 等于“所求出口的 grant”，头 flit 堵住则该输入整队冻结，即使其它出口空闲。测量 bus_16x16：输入阻塞 31% 周期而出口空闲 52%。XBAR FIFO 把 ready 变成“本 crosspoint 有空位”，输入可继续按目的地分流。

RR 实现为双优先级编码器 + mask（mask 即状态，不是二进制指针），避免循环 adder/%。NUM_REQ=8 时从约 53 级逻辑降到与 FIX 同量级的常数深度。grant_take 只在“仲裁器自己的决定被消费”时前进；burst-lock 期间按拍 fire 不得推进 RR，否则 B 拍突发会跳过 B−1 个请求者（B=2、NUM_IN=4 会饿死偶数口）。

7.3.3 Hardware

Burst-lock 与 QoS

  • HAS_LAST=1：出口锁定到获权输入，直到选出的 flit.last=1。锁定期间 grant = req & lock_oh，走未滤波的 req，低 QoS 突发不会被后到的高 QoS 打断（否则死锁/撕裂突发）。
  • RR-QoS：温度计向量按位或得当前最高档；某请求者被支配 iff 合并温度计有它没有的位。全 0 时与纯 RR 位级相同。QOS_W=0 时整臂折叠，与无 QoS 网表一致。
  • qos_track：每个温度计档一个加减计数，push/pop 镜像 FIFO 读写，队列最大值可随 pop 下降。

7.4 Credit

7.4.1 I/O

模块端口
lb_credit_egress in_data/in_valid/in_ready，out_data/out_valid（无 ready），credit_return
lb_credit_ingress in_data/in_valid（无 ready），out_data/out_valid/out_ready，credit_return=do_rd

7.4.2 Function

复位后 egress.credit = CREDIT_INIT。发送 −1，return +1，同拍可抵消。credit=0 则 out_valid=0、in_ready=0。

ingress 写侧相信 credit 保证非满，do_wr = in_valid && !full；若仍收到满写，该拍被丢弃。这是最危险的静默失效，故仿真断言 + 静态脚本 check_credit_pairing.py 双重约束。

7.4.3 Hardware

FIFO 指针带绕回位。DEPTH 为 2^n 时自然 +1；否则在 DEPTH−1 处翻转绕回位。与 lb_sw_out_fifo 指针方案由 check_fifo_ptr_parity.py 防漂移。egress 允许“正在发送的那一拍零延迟 return”，此时 credit 仍为满值但 do_send=1，不算 over-return。

7.5 Link

7.5.1 I/O

lb_link_top 统一 credit 接口：in_flit/in_valid、in_credit_ret；out_flit/out_valid、out_credit_ret。参数 CREDIT_NODE、ASYNC、IN_PIPE、INGRESS_DEPTH、EGRESS_CREDIT、BCA_DEPTH、SYNC_STAGES。

7.5.2 Function

形态参数行为
(a) PIPECREDIT_NODE=0int_pipe：前向 payload+valid、反向 credit 打拍。无缓冲，一条端到端 credit 环。
(b) NODECREDIT_NODE=1, ASYNC=0ingress FIFO + egress。两条分段 credit，不跨域。
(c) BCACREDIT_NODE=1, ASYNC=1(b) + 异步。ingress 在 clk_w，egress 在 clk_r，中间 bca_slv/mst。Credit 不跨域。

Unify 不是 lb_link_top 的第四模式，而是独立的 lb_link_unify_data + 通道 adaptor，同样走 credit_ingress → gearbox → credit_egress。

7.5.3 Hardware

REQ Unify adaptor 把 INIU/TNIU 的 {CMD[+MOD], WD} 拆成 gearbox 的 {data, mask=strb, last, sb={cmd,dest,src}, lane=addr 相位, total_bytes}。CMD/qos/mod 对 gearbox 不透明。

RSP_RD adaptor：HAS_MASK=0，mask 由范围重建。sideband = {src, qos, int_id, resp, user, trans_last}。DOWN 后必须恢复 trans_last 与 last 的蕴含关系。

7.6 Unify Gearbox

7.6.1 I/O

lb_unify_gearbox：in/out data、mask、sb、lane、total_bytes、last、valid/ready。IN_DATA_W 与 OUT_DATA_W 自动决定 UP 或 DOWN；相等则直通。

7.6.2 Function

拍边界由地址决定，不由事务起点决定。UP（窄→宽）：输入拍 k 进入输出拍的子槽 j = k mod RATIO；首拍 j 可以非 0，低槽填 0 且 mask=0；j=RATIO−1 或 in_last 时 flush。DOWN（宽→窄）：按区间相交发射子拍，不以 mask 是否非零为准（稀疏写全 0 strb 合法，用 mask 会把 last 标错）。

in_lane 即地址相位；in_total_bytes 为突发常量，每拍重复。

7.6.3 Hardware

lo = in_lane
hi = lo + total_bytes
k_in = (lo >> log2(IN_B)) + beat_n     // 绝对输入拍号
in_base = k_in << log2(IN_B)            // 替代 lo 对齐后再 + beat*IN_B 的乘加

无 function/endfunction。RATIO、移位假设位宽为 2^n，elaboration 检查。

7.7.1 I/O

7.8.1 I/O

模块接口ENABLE=0

7.9 Common

8. Low Power Design

BASIC-CORE 不含 QChannel / 时钟门控握手 IP。低功耗相关设计选择：

  • 事务级仲裁降低每拍仲裁翻转。
  • Credit 单向 valid + 稀疏 credit_return，避免长距离 ready 反打。
  • QOS_W=0、ATOMIC_EN=0、XBAR_FIFO_DEPTH=0、各 PIPE ENABLE=0 时对应逻辑整臂折叠。
  • 四通道分离避免读命令在写数据物理通道上空占带宽（从而少翻转无用宽数据总线）。

电源域隔离、下电阻塞与错误响应属于 adapter / 系统 CRM，见 adapter 设计文档，不在本 RTL。

10. Cost / Area

文档记载的综合目标（具体 cell 数未写入 motivation 正文）：

  • 1.8 GHz：REG2REG 无 VIO。
  • 2.5 GHz：REG2REG VIO < 10 ps。

面积敏感点（实现已做的结构选择）：

  • CMD TABLE 深度 = Pendingtrans，读写共享一池，避免双倍表项。
  • 读交织 assembly 按 FB×Pendingtrans，不要按整笔事务深度。
  • RSP_RD 不带 byte_valid。
  • 路由译码挪到 FIFO 写侧，只增加 NUM_OUT bit/项，换出仲裁拍的地址 mux。
  • lane_pack 去掉桶形移位，STRB 用拍级比较 + 温度计。

11. DFX

  • 仿真断言由 LB_NO_ASSERT 关闭，便于 lint 干净编译。覆盖：区域重叠、credit 满写/超预算、FIFO 指针越界、同 ID 双活、原子未使能却来原子 opcode、trans_last 破坏、user 宽度截断等。
  • 静态检查（RTL 注释引用，生成器侧）：credit 配对、FIFO 指针奇偶一致性、同域 PIPE 强制打开。
  • 无内建扫描/MBIST 包装；寄存器堆（credit FIFO、XBAR FIFO、cmd_table、frag buffer、BCA regfile）需在芯片 DFT 流程中按普通 RAM/flop 处理。
  • 复位：各模块异步断言。跨域必须两侧复位策略与 BCA gray 初值（0）一致，避免虚假 empty/full。
