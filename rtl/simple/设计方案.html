1. Overview

1.1 Purpose

本文档供 DE / DV 使用。描述 simple 适配器（并行裁剪树 rtl/simple/）的功能与 RTL，不修改 litebus_rtl/，不替换全功能 rtl/adapter_*.v。模块名与全功能树相同，只编本目录，不可混编。AXI4 顶层不含任何 AXI5 端口或参数。

  • 第 2 章：各协议共用接口（时钟复位、Q-Channel、LiteBus REQ/RSP）。
  • 第 3 章：LiteBus 描述符打包（CMD / WD / REQ_W）。
  • 第 4–5 章：约束与 feature。
  • 第 7 章：按 AXI4 / AXI5 / APB 以及 QCH、atomic、ip_fail、err_rsp 给出 I/O、功能与电路。

本 IP 做 协议转换；跨时钟/电源异步由链路 BCA 完成。

1.2 Top Diagram

请求方向固定如下。BCA 成对出现：bca_slv 在可下电域，bca_mst 在常上电域。adapter_err 插在 LiteBus 与从域 bca_slv 之间。

IP Master→ adapter_mst→ bca_slv→ bca_mst→ LiteBus→ adapter_err→ bca_slv→ bca_mst→ adapter_slv→ IP Slave

可下电域（IP + 适配器 + 该侧 BCA）常上电（互联、对侧 BCA、adapter_err）

图 1-2 说明

本图只画 请求方向（Master → Slave）。响应完全相反。子图表示电源域，不是时钟域。

  1. 可下电主域：IP Master、adapter_mst、主域 bca_slv 同电。主机只看见适配器的 AMBA slave 口。适配器打成 REQ_R/REQ_W，并跑本域 QCH。
  2. 主域 bca_slv：异步桥写侧。下电前必须完成 QCH，否则对侧指针失配。
  3. 常上电 bca_mst（主域对侧）：读出请求送给 LiteBus。mst 的 lbus_pwrdn=1 时清读指针。
  4. LiteBus：本目录不实现，只规定 IP 侧 valid/ready。
  5. adapter_err：必须在进入从域 bca_slv 之前（D23）。上电透传；intercept 自锁后回 FAIL，避免写进已下电的从域桥。
  6. 从域对侧 bca_slv：常上电。slv 的 lbus_pwrdn 在此清指针。
  7. 可下电从域：bca_mst + adapter_slv + IP Slave。适配器把 REQ 展开成 AMBA master。
  8. 虚线 lbus_pwrdn：仅 DOWN 后为 1。mst 只打到主域对侧 bca_mst；slv 同时打到从域对侧 bca_slv 和 adapter_err.intercept。
  9. 配对：axi4 对 axi4，axi5 对 axi5，apb 对 apb。

响应：IP Slave → adapter_slv → bca_mst → bca_slv → adapter_err → LiteBus → bca_mst → bca_slv → adapter_mst → IP Master。拦截时 RSP 由 adapter_err 本地产生。

1.3 Workflow

工作流分两类：AMBA↔LiteBus 数据流与 Q-Channel 控制流。QCH 的 busy 来自协议侧尚未完成的 AXI/APB 事务。

图 1-3 说明

上半是数据，下半是电源握手。PPU 不进 LiteBus，只拉各域 qreqn。

  1. 一次写：IP Master 在 mst 上 AW+W → REQ_W → BCA → LiteBus →（上电）err 透传 → slv 访问 IP Slave → B 反向变成 RSP_WR → mst 出 B。读把 AW/W/B 换成 AR/REQ_R/R/RSP_RD。
  2. mst 下电：qreqn=0。无在途则立即 DOWN。有在途则 DENY 或 QUIESCE。打开 ADP_QCH_TO 时 QUIESCE 过久拉 irq_qch_to，再按 qch_to_mode 等待或本地回错（7.4.4）。
  3. slv 下电：不能 DENY。QUIESCE 停接新 REQ，ost 清零后 DOWN。lbus_pwrdn 清从域对侧 bca_slv，并作 intercept。
  4. err 必须在从域 BCA 之前：从域断电后 bca_slv 写口不可用。先写进桥再拦截会丢数据和指针。

3. Descriptors

LiteBus 描述符与 v0.9 §3 相同。从 REQ_W 取 CMD 必须先跳过 MOD_PW。

图 3 说明

  • CMD = {qos, opcode, addr, len, txnid, user} = REQ_R。
  • 必须跳过 mod：否则 addr/len/txnid 左移 MOD_PW。正确：先去掉 WD，再从 {CMD,mod} 丢掉 MOD_PW。
  • mod：AXI4/APB 为 1-bit dummy（打包对齐，不是原子）。AXI5 才是 3-bit AWATOP[4:2]。
  • txnid（1.8 起读写通道独立编号）：读 = 读槽 0..MAX_RD_OST-1；写 = 写槽 0..MAX_WR_OST-1。相同数值靠 RD/WR 通道区分。默认 256+256 在 ID_W=8 下合法。APB 绑 0。
CMD   = {qos, opcode, addr, len, txnid, user}
WD    = {data, strb, last, txnid}
REQ_W = {CMD, mod, WD}
live_cmd = req_w[WD +: CMD+MOD][MOD +: CMD]
opcode值方向谁使用
LB_OP_RD4'h1REQ_RAXI4 / AXI5 / APB
LB_OP_WR4'h8REQ_WAXI4 / AXI5 / APB
ATOMIC_STORE / LOAD / SWAP / COMPAREC / D / E / FREQ_W仅 AXI5

响应：LB_RESP_OK→OKAY；AXI5 的 ATOMIC_FAIL→ATOMIC_FAIL_RESP（默认 EXOKAY）；其余→SLVERR / LB_RESP_FAIL。AXI4 不解码原子响应。

4. Design Constraints

  • 未与适配器完成 Q-Channel 握手就单独复位/下电一侧 BCA，可能导致对侧指针失配。须先握手，再靠 lbus_pwrdn 清指针。
  • reg_qdeny_en / reg_err_en /（若存在）qch_to_en / qch_to_lim / qch_to_mode 不应在 qreqn 拉低与握手完成之间翻转。
  • AXI：仅整宽 INCR，*size=log2(DATA_W/8)，地址按 DATA_W 对齐。禁止窄带、WRAP。MAX_RD_OST/MAX_WR_OST ≥1 且各自 ≤ 2**ID_W。同一 AXI ID 未完成前反压（无 ROB）。
  • AXI4 顶层禁止出现 awatop、AXI5_EN、原子 opcode、adapter_atomic。
  • AXI5 原子：awlen=0。LOAD/SWAP/COMPARE 与普通读串行共用 R。
  • APB：len=0。mst 只在 SETUP（PSEL && !PENABLE）捕获。
  • 从域真正断电后，请求必须在 adapter_err 被截住，不得进入从域 bca_slv。
  • 超时功能必须用 `ifdef ADP_QCH_TO 包起来；未定义时无超时端口、无计数器。
  • ERR 模式本地回错后，迟到的响应必须丢弃，且对应表项在对侧响应到达（或 DOWN/复位）前不得复用，见 7.4.4。
  • 无内部异步 fifo。WRAP+SPLIT 均不实现。与 rtl/adapter_*.v 不可混编。

5. Requirements / Feature Description

适配器把 AMBA 转换成 LiteBus REQ/RSP，并允许 PPU 经 Q-Channel 安全下电。异步隔离由 BCA 完成。

5.1 Feature List

  • AXI4、AXI5（AWATOP）、APB4 双向转换；AXI4 / AXI5 为 独立顶层。
  • AXI 多 outstanding：MAX_RD_OST / MAX_WR_OST 例化参数传入，默认 256 / 256。txnid = 本通道表项索引。
  • Q-Channel：mst 可 DENY / 反压 / 本地回错；slv 等在途完成后 DOWN。
  • QCH 握手超时（独立 feature，宏 ADP_QCH_TO）：qch_to_en + qch_to_lim；超时后 qch_to_mode 选择 WAIT 或 ERR；上报 irq_qch_to。
  • slv lbus_pwrdn → 从域对侧 bca_slv 清指针，并作 intercept。
  • 从域断电兜底：常上电 adapter_err_rsp（D23）。
  • 不包含：窄带、WRAP、ROB、同 ID 重映射、mst SPLIT、slv SBS、Addition。AXI4 不包含 原子。

6. Open Issues

  • lbus_pwrdn 由 LiteBus 侧 BCA 消费的握手时序属互联协作。
  • 不实现 Addition；与冻结 ext_core 无 addition 针脚一致。
  • ERR 模式下若对侧响应永远不来、且 PPU 又取消下电，对应表项保持占用直到 RSP 或复位，可能暂时降低有效 ost。属预期行为。

7.1.2 Function Description

AXI4 整宽 INCR 与 LiteBus 互转。读 txnid = 读槽号，写 txnid = 写槽号。同一 AXI ID 未完成前 ready=0。

  • reg_qdeny_en=1 且 busy：DENY。
  • reg_qdeny_en=0 且 reg_err_en=0：新 AR/AW 反压，在途走完后 DOWN。
  • reg_err_en=1：新请求不进 LiteBus，AXI 回 SLVERR；已收下的仍发完 REQ（与超时 ERR 不同，见 7.4.4）。
  • slv：QUIESCE 等 AXI 在途为 0 再 DOWN；之后 ip_fail / err_rsp 回 FAIL。

7.1.3 Hardware Description

图 7-1 说明（mst AXI4）

  1. 准入 ADM：读/写表有空槽；该 AXI ID 无未完成事务；QCH 未反压；err_mode 未截断。全部满足才 ready=1。
  2. 写打包：每一拍 W 一拍 REQ_W。txnid 来自该笔 AW 的写槽。wlast 只影响 WD.last。
  3. 读：AR 后只发一次 REQ_R（len=arlen），R 拍全部来自 RSP_RD。
  4. 响应多路：RSP_*.txnid 索引表取出 AXI ID。ERR 模式迟到响应丢弃（7.4.4）。

  6. 没有 adapter_atomic：AXI4 图故意去掉 AWATOP 译码。

图 7-1b 说明（slv AXI4）

7.4.3 Hardware Description

图 7-4 说明

  1. UP：正常工作。qacceptn=1，lbus_pwrdn=0。
  2. DENY：仅 mst。告诉 PPU 现在不能下电；AXI/APB 继续。离开 DENY 必须 qreqn=1。
  3. QUIESCE：停接新业务（或 err_mode 下新请求本地回错）。o_quiesce = QUIESCE && !reg_err_en；o_err_mode = QUIESCE && reg_err_en。qactive = busy || QUIESCE。

7.4.4 QCH 超时（独立 feature，ADP_QCH_TO）

未定义宏：本节电路不存在，超时端口不出现。

图 7-4b 说明

  1. 计数器只在 QUIESCE 且 qch_to_en=1 时运行。离开 QUIESCE 清零。
  2. qch_to_lim=0：进入 QUIESCE 的下一拍即超时（仍要求使能）。
  3. WAIT 与 ERR 都不增加新的 QCH 状态。WAIT 完全依赖真实在途结束；ERR 通过让协议把 busy 拉低，从而走原来的 QUIESCE→DOWN。
  4. irq_qch_to 粘滞：超时置位；DOWN、qreqn=1 或复位清除。模式只在超时拍采样。

模式 0 — WAIT：协议侧无额外动作。软件可继续等，或把 qreqn 拉回 1 放弃下电。

模式 1 — ERR：已经向对侧发出的请求稍后还可能回来。AXI/APB/LiteBus 都只允许每个事务完成一次，因此本地回错之后迟到响应必须丢弃，且该表项在对侧响应到来前不能发给新事务。

位含义
axi_done已经向 AMBA 完成（R last / B / PREADY）
lbus_done已经与 LiteBus 完成对应 RSP（或 slv 已发出 FAIL）

QCH busy 只看 !axi_done 的槽。ERR 后 busy 可以变 0，允许 DOWN；LiteBus 迟到响应在后台丢弃。

图 7-4c 说明

  1. 主机已经拿到 B，禁止再出第二次 B。迟到 RSP_WR 只握手吃掉。
  2. 读同理：补齐剩余 R 拍（SLVERR + 最后 rlast），迟到 RSP_RD 丢弃。
  3. 已接受的 AW 必须最终给 B；未接受的 W 反压。
  4. axi_done && !lbus_done 期间该 txnid 仍占用。若 PPU 取消下电，新 AW/AR 不得拿到这个槽，否则会吃到旧 RSP。
  5. 真正 DOWN 后 lbus_pwrdn 清 BCA，残留 RSP 不再进入本模块。

图 7-4d 说明

  1. slv 是 AXI master，无法撤销已发出的 AR/AW。ERR = 放弃等待下游，立刻向上游回 FAIL，以便 DOWN。
  2. IP Slave 随后给出的 R/B 丢弃。若紧接着 DOWN，从域断电，这些 AXI 边沿也会消失。
  3. APB slv：WAIT 中超时则向 LiteBus 回 FAIL，下游 PREADY 迟到则忽略。

8. Low Power Design

  • 可下电域：IP + 适配器 + 该侧 BCA。常上电：对侧 BCA、LiteBus、adapter_err。
  • mst：在途回收（或 DENY / 本地回错）后再 DOWN；lbus_pwrdn 清主域对侧 bca_mst。
  • slv：查看 AXI/APB outstanding，完成后再 DOWN；lbus_pwrdn 清从域对侧 bca_slv，并作 intercept。
  • 定义 ADP_QCH_TO 时：QUIESCE 过久拉 irq_qch_to。WAIT 不强制断电；ERR 通过本地回错把 busy 拉低后再走正常 DOWN。迟到响应当丢弃。

9. Performance

适配器本身为同域同步逻辑。跨时钟延迟由 BCA 决定，不在本模块报价。

路径量级（不含 BCA）
AXI 写 AW/W → REQ_W握手当拍打包；B 等 RSP_WR
AXI 读 AR → REQ_RAR 后约 1 拍发 REQ_R；R 直通 RSP_RD
APB SETUP → REQSETUP 当拍发 LiteBus；PREADY 等整条链路 RSP
outstanding读 ≤ 256（默认）+ 写 ≤ 256（默认）；无 ROB 重排

10. Cost / Area

相对全功能适配器：无窄带 packer、ROB、SPLIT/SBS、异步 fifo。面积主要是 AXI/APB FSM、ost 表（默认 256+256 项）、qch 2-bit。ADP_QCH_TO 打开时再加 QCH_TO_W 计数器、IRQ、以及 ERR 模式的 axi_done/lbus_done 与丢弃通路。未定义宏则超时相关为 0 面积。AXI4 顶层不含 atomic。

11. DFX

可观测：

  • qacceptn / qdeny / qactive / lbus_pwrdn
  • o_quiesce / o_err_mode
  • intercept_on
  • 定义 ADP_QCH_TO 时：irq_qch_to、qch_to_en、qch_to_lim、qch_to_mode

下电后仍有访问：mst 为 SLVERR 或反压；互联侧为 err_rsp 回 FAIL。未做 QCH 就复位 BCA 可能导致指针不匹配（第 4 章）。irq_qch_to 表示 QUIESCE 握手超时：WAIT 时查在途是否卡住；ERR 时查是否已本地回错以及是否仍有 lbus_done 未置位的孤儿槽。
