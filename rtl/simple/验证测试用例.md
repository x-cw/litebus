# 简易适配器验证测试用例

Author: xucw　·　Version **v1.0**　·　Date: 11/09/2026  
对照：`rtl/simple/设计方案.md` **simple-1.8**。DUT 仅 `rtl/simple/`，禁止与 `rtl/adapter_*.v` 混编。  
HTML：同目录 `验证测试用例.html`。

## 1. 范围与环境

| 项 | 约定 |
|----|------|
| DUT | `rtl/simple/adapter_*.v` + `adapter_defs.vh`（引入 `rtl/adapter_ip_defs.vh`） |
| 模型 | `rtl/simple/sim/adapter_slv_model.v`、`axi_slave_mem.v`（从仓库 `sim/` **复制**，全功能 TB 仍用原文件） |
| TB 目录 | `rtl/simple/sim/tb_adapter_simple_*.v`（已从仓库根 `sim/` **搬迁**） |
| 仿真器 | Icarus Verilog 12，`-g2005`。工作区路径含空格时请拷到无空格目录再编 |
| 通过判据 | 日志含 `ALL TESTS PASSED` |
| 宏 | 默认 **不**定义 `ADP_QCH_TO`。仅 `tb_adapter_simple_qch_to` 加 `-DADP_QCH_TO`，且 **只编** `adapter_qch.v` |

```text
# 在 rtl/simple 下（无空格路径）
make TOP=tb_adapter_simple_unit run
make regress

# QCH 超时（独立 feature）
make TOP=tb_adapter_simple_qch_to run
```

```text
iverilog -g2005 -I rtl -I rtl/simple -s tb_adapter_simple_unit -o t.vvp \
  rtl/simple/adapter_*.v rtl/simple/sim/adapter_slv_model.v \
  rtl/simple/sim/axi_slave_mem.v rtl/simple/sim/tb_adapter_simple_unit.v
vvp t.vvp

iverilog -g2005 -DADP_QCH_TO -I rtl -I rtl/simple -s tb_adapter_simple_qch_to -o t.vvp \
  rtl/simple/adapter_qch.v rtl/simple/sim/adapter_slv_model.v \
  rtl/simple/sim/axi_slave_mem.v rtl/simple/sim/tb_adapter_simple_qch_to.v
```

LiteBus `valid`：一拍握手后拉低，禁止跨两个 posedge 保持。APB 只在 SETUP（`psel && !penable`）捕获。

## 5. 计划用例（设计有、本阶段不编进回归）

不要改设计文档去迁就缺口。P-01/P-03/P-04/P-05 已在 1.8 RTL 闭环；下表只保留仍未进回归的项。

| ID | 缺口 | 说明 |
|----|------|------|
| P-02 | ost 默认 256，TB 例化 4 | 参数可例化；TB 一律 `#(.MAX_RD_OST(4),.MAX_WR_OST(4))` 以缩短仿真。不扫满 256 表 |
| P-06 | APB `err_mode` 新 SETUP → PSLVERR | `busy=state!=IDLE` 与 IDLE 互斥，空闲 `qreqn=0` 走立即 DOWN。现测 A-04 |
| P-07 | slv AXI5 LOAD/SWAP 的 AXI R | slv 等下游 `rvalid`；`axi_slave_mem` 为 AXI4 写通道不回 R。mst 侧 M-11 已覆盖 LiteBus B+R |
| P-08 | `LB_RESP_ATOMIC_FAIL` → EXOKAY | 模型比较失败仍回 OK。需可注入 `2'b10` 的模型或桩 |
| P-09 | 迟到 RSP 丢弃（系统级） | mst/slv 已按 `axi_done`/`lbus_done` 接线；回归仍以 Q-01…Q-05 测 `adapter_qch` |

## 6. 已知仿真陷阱（沿用前次报告）

1. **QCH `err_mode` 不得打断已接受的写**（RTL）：在途 `wr_data` 仍走 LiteBus W。M-09 先 AW 再 `qreqn=0`。
2. **APB idle + `qreqn=0` 是 DOWN 不是 QUIESCE**（TB）：`o_err_mode` 为 0；A-04 查 `lbus_pwrdn` 且不得 PREADY。
3. **REQ_W 的 CMD 从 `{CMD,mod,WD}` 取**：模型用 `req_w[EXT_REQ_W-1 -: EXT_CMD_W]`。
